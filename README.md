# Coste de un viaje en coche

Calcula kilómetros, litros y euros de un viaje en coche con el precio medio del carburante de hoy en cada provincia, y cuánto paga cada uno.

Sitio: https://adrianezd.github.io/coste-viaje/

`precios.json` lo regenera cada día la Action `.github/workflows` con `actualizar.py` (datos del Ministerio para la Transición Ecológica).
